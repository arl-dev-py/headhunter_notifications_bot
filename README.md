# HeadHunter Notifications Bot

Telegram bot for monitoring **new HeadHunter vacancies** by your criteria.

Get notifications about matching vacancies **instantly** in Telegram!

## Quick launch

1. Clone repository
git clone https://github.com/arl-dev-py/headhunter_notifications_bot.git
cd headhunter_notifications_bot

2. Install dependencies
pip install -r requirements.txt

3. Create .env file
cp .env.example .env

Edit .env:
BOT_TOKEN=your_token_from_BotFather
HH_EMAIL=your_email_hh.ru
HH_PASSWORD=your_password_hh.ru

4. Run bot
python main.py

Done! Bot starts monitoring vacancies.
Don't forget to add your search criteria to .env!
